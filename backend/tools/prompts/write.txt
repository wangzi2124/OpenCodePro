Create a new file or overwrite an existing file with content.

Parameters:
- file_path: Absolute path to the file to write (required)
- content: The content to write to the file (required)

Notes:
- This will OVERWRITE existing files completely
- Use edit_file for making targeted changes to existing files
- Always use absolute paths
- The parent directory must exist

Examples:
- Create a new file: write_file(file_path="/path/to/new_file.py", content="print('hello')")
